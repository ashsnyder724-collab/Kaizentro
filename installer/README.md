# Installer Plan

Kaizentro will ship as a Windows desktop application.

## Alpha Packaging

Initial package target:

- Self-contained Windows build
- Internal installation zip
- Later MSIX/MSI installer

## Release Candidate Packaging

Future installer should include:

- Kaizentro Desktop
- SQL Server connection configuration
- Sample database seed option
- Desktop shortcut
- Versioned release notes
- Upgrade path
