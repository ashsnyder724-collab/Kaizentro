# Security policy

This is an early Windows desktop alpha, not a hosted multi-user service. Use only controlled evaluation data until the data, import/export, storage, and deployment boundaries have been reviewed. Keep operating-system access restricted, encrypt the device and backups, and verify downloads from the maintainer.

Report vulnerabilities privately to info@eliteindustrialsolutions.com. Do not include passwords, signing keys, production data, or employer information in public issues. Provide a minimal synthetic reproduction.

Source and dependency changes should pass the build/test checks. Keep signing material and local environment settings out of source control. Repository privacy, access membership, required checks, and account MFA are managed separately from these files.
